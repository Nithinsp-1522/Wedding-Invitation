# Ancient Thaliola Wedding Invitation — Enhanced Edition

A premium-looking, responsive static wedding invitation made with plain HTML, CSS and JavaScript. It is ready for free GitHub Pages hosting.

## Features
- Ancient thaliola / palm-leaf-inspired paper grain and ornamental frames
- Deep wine-red and antique-gold palette
- Decorative intro screen and animated scroll reveals
- Live countdown to 31 January 2027, 12:00 PM India Standard Time
- Responsive navigation for phones
- Couple portrait image support
- Wedding detail cards, decorative main venue map-preview box, and compact reception location card
- Google Maps search button
- No backend, database, music, build system or paid hosting required

## Personalize before publishing
1. Open `script.js`.
2. The current names are set to `Nishanth S P` and `Gayathri Devi B P` in `script.js` and `index.html`. Edit both files if you want to change them later.
3. Put the couple's portrait in `assets/couple-photo.jpg`.
4. Confirm the venue's spelling and exact map pin. The current map button searches Google Maps for `Devi Community Hall, Cheruppaolor`; the illustrated map is decorative, not a live map.
5. The reception card links to Sree Devi Auditorium, Thirunanthikarai using the Google Maps link supplied. If you obtain a confirmed exact Google Maps place link for the wedding hall, replace `mapsUrl` in `script.js` with that URL.

## Preview
Open `index.html` in a browser. Internet access is needed for Google Fonts; system fallback fonts are used otherwise.

## Deploy free using GitHub Pages
1. Sign in at https://github.com/ or create an account.
2. Create a **public** repository named `wedding-invitation`.
3. Extract this ZIP, then upload the contents of the folder to the repository root (do not upload only the ZIP): `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
4. Open repository **Settings → Pages**.
5. In **Build and deployment**, set **Source** to `Deploy from a branch`.
6. Choose branch `main` and folder `/(root)`, then click **Save**.
7. Wait for the publish workflow to complete. The site URL is normally `https://YOUR-GITHUB-USERNAME.github.io/wedding-invitation/`.
8. Open that URL on desktop and phone. Upload/commit any changes to publish the updated site.

## Privacy note
A public repository and GitHub Pages site can be seen by anyone. Only publish names, photos and details you are comfortable sharing publicly.
